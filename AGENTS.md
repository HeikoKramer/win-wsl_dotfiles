# Repository Guidance for AI Agents

All AI agents working in this repository **must** read and comply with the following rules:

1. **Language**: Use English for all code comments, documentation, commit messages, and other text authored in this project.
2. **Emoji usage**: Do not add emojis or other decorative symbols to source code, console output, documentation, or comments.
3. **Scope**: These rules apply to the entire repository unless a more specific AGENTS.md file overrides them.

Thank you for following these guidelines to keep the project consistent and professional.
